# Release Notes — v2.3.4 (versionCode 18)

## es-419 (Español Latinoamérica)

- Corregido un bucle de reintentos del banner que repetía peticiones cuando no había anuncio disponible.
- El anuncio nativo ya no se solicita de nuevo si ya está cargado o hay una carga en curso.
- Menor consumo de datos y mejor estabilidad al volver a la aplicación.

## en-US (English)

- Fixed a banner retry loop that repeated requests when no ad was available.
- The native ad is no longer requested again while it is loaded or loading.
- Lower data usage and better stability when returning to the app.
